# `tensorplate-protocol` (Rust crate)

Rust types and serialization helpers for the schemas in
[`../schemas/`](../schemas/). Shared by `agent`, `cli`, and `observability`.

This crate is library-only. It must not depend on `agent`, `cli`, or
`observability`.

The crate skeleton is created in V01-E01-F03; types land in V01-E02.
