# TensorPlate v0.1.0 release notes

> Draft for the final release owner. Do not publish until the `v0.1.0`
> tag, artifacts, checksums, validation evidence, clean-room evidence, and
> sign-off are complete.

TensorPlate v0.1.0 is the first public installable release for a
Jetson-class edge inference appliance loop.

## Supported environment

- Jetson Orin Nano 8GB Super hardware floor.
- JetPack 6.x with L4T 36.x.
- `arm64` Debian packages attached to this GitHub Release.
- Local-only default endpoints through Unix sockets and loopback.

## Known limitations

- No hosted control plane, fleet rollout, OTA update, RBAC, SSO, or cloud
  dashboard.
- No APT repository in v0.1.0; install from GitHub Release assets.
- No container-only install path.
- Kria K26/K24 and Vitis AI execution are reserved for later releases.
- `tensorplate-backend-python-pytorch` does not vendor PyTorch; install
  the platform-appropriate PyTorch stack separately.
- The serving endpoint defaults are local-only. Exposing them beyond the
  device is unsupported in v0.1.0.
